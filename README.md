# Linux Production Bash Scripts

A collection of **30 practical Linux Bash scripts** designed to automate common system administration, monitoring, maintenance, backup, networking, and DevOps-related tasks.

These scripts were extracted and organized from a Linux production shell scripting reference, with each script maintained as an individual `.sh` file for easier learning, testing, and reuse.

* 📦 File Backup & Compression
* 🖥️ System Monitoring & Health Checks
* 👤 User Account Management
* 🔐 Password Generation & File Encryption
* 📋 Log Analysis
* 💾 Database Backup & Cleanup
* 🌐 Network Connectivity & Interface Monitoring
* 🔄 Directory Synchronization
* 📊 CPU & Disk Usage Monitoring
* ⏰ Cron Job Scheduling
* 🚀 Software Installation
* 🔧 Service Management
* 🐙 Git Repository Updates
* ☁️ Remote Server Backup
* 🔑 Remote Script Execution
* 🧹 Data & Backup Cleanup
* 📁 File and Folder Management

## 🎯 Purpose

The main goal of this repository is to provide a practical collection of Bash scripting examples that can be used for:

* Linux system administration practice
* Bash scripting learning
* DevOps practice
* Production automation concepts
* Server monitoring and maintenance
* Backup and recovery automation
* Linux interview preparation

## ⚠️ Important Note

These scripts contain example paths, usernames, hostnames, package names, database credentials, and other placeholder values. **Review and customize the variables before running them in a real environment.**

Always test scripts in a safe environment before using them on production systems.

## 🛠️ Requirements

Most scripts require:

* Linux/Unix-based operating system
* Bash
* Standard Linux utilities

Some scripts may additionally require tools such as:

* `curl`
* `rsync`
* `git`
* `openssl`
* `mysql` / `mysqldump`
* `ssh`
* `systemctl`
* `ifconfig`

## 📚 Learning Focus

This repository is intended as a hands-on reference for improving:

**Linux → Bash → System Administration → Automation → DevOps**

More scripts and production-oriented automation examples can be added as the collection grows.
